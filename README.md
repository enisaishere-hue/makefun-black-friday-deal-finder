Bargain Beacon — a Black Friday and Cyber Monday deal finder. 34 real deals checked live on 27 November 2026 at Amazon, Target, Best Buy, Walmart, Kohl's, Wayfair, Sam's Club and LEGO, each with its sale price, usual price, discount, store link, check time and source — plus an honest verdict on whether it is really a deal (new low, strong price, or routine sale) and a same-product comparison where two stores carry it. Search, filters by category, store, discount and verdict, and sorting by discount, saving or price all work offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser or on a phone.
